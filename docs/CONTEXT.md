# 视频生成与运营

围绕账号定位，将公开资料转化为数字人口播作品，并根据发布表现调整后续选题。首期一个账号运行，为多账号运营保留业务归属。

## Language

**运营账号**：拥有独立内容定位、关注主题、形象、音色和运营策略的内容主体。一个运营账号的选题历史和表现不自动成为其他账号的运营依据。
_Avoid_：用户、平台账号（指代该内容主体时）

**平台账号**：抖音等发布平台上的外部身份，由运营账号绑定并授权发布和读取作品数据。
_Avoid_：运营账号

**关注主题**：运营账号持续关注的一类内容，如 AI 办公、会议记录、文档处理。主题的推荐优先级不改变内容必须符合账号定位的要求。
_Avoid_：选题、热点

**事件资料**：关于某个事件或实质性进展的来源内容及时间、出处、热度依据。同一事件资料可以支持不同账号的不同选题。
_Avoid_：口播稿、作品

**热点**：有可核验热度依据的事件内容；其热度不等于对某个运营账号的相关性。
_Avoid_：最新消息、搜索排名靠前的结果

**近期资讯**：符合所配置时间窗口的事件内容，但可能没有可核验的热度依据。无合格热点时可在同一账号主题范围内补位。
_Avoid_：热点（无热度依据时）

**账号选题**：某个运营账号针对事件资料选定的内容角度，包含唯一主主题和推荐理由。
_Avoid_：关注主题、事件资料

**主主题**：一条视频的唯一主要主题，决定该作品表现的主题统计归属。其他匹配主题仅作为辅助标签。
_Avoid_：多主主题

**生产任务**：一次触发后，从候选选题到最终成片的生产过程，目标产出一条视频，允许因无合格选题而跳过。
_Avoid_：发布记录、定时计划

**人工确认**：运营者对当前版本的选题、口播稿、成片发布信息或策略建议作出的继续执行决定。内容修改后的新版本不自动继承旧确认。
_Avoid_：内容检查（它是另一个判断过程）

**音色资料**：参考录音、对应文字及来源说明构成的音色配置，经试听确认后用于账号口播。
_Avoid_：训练后的音色模型（首期不训练）

**成片**：由数字人画面、最终配音和同步字幕组成的可播放视频，具有明确的内容版本和检查结果。
_Avoid_：已发布作品

**发布记录**：将指定成片及发布信息提交给指定平台账号的一次发布意图及其结果。提交请求与平台确认发布成功是不同阶段。
_Avoid_：生产任务

**指标快照**：某条已发布作品在某个实际采集时刻的指标观测，区分真实零值、缺失及不支持。多次累计快照不能直接相加。
_Avoid_：增量数据（未经差分计算时）

**观察窗口**：单条作品发布后用于测量表现的时长，首期主要使用发布后 24 小时。
_Avoid_：回看范围

**回看范围**：在一次主题比较中纳入哪些发布日期的作品，首期默认最近 30 天。
_Avoid_：观察窗口

**策略建议**：根据当前账号表现提出的主题推荐优先级变化，需人工确认才生效。探索性建议明确表示证据不足，不宣称已证明主题优劣。
_Avoid_：生效策略

**策略版本**：账号已确认采用的一组主题推荐优先级及其依据，供后续新生产任务使用。
_Avoid_：策略建议、生产触发

**联调预算**：首期全部实际付费 API 调用共同占用的额度，总计 200 元，其中首轮验证不超过 50 元。
_Avoid_：单条视频成本、每日预算
