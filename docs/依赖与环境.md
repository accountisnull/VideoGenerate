| `uvicorn` | ASGI 服务运行器 |

| 依赖 | 用途 |
| --- | --- |

该组是第 1 人的接入起点，实际百炼模型、地域、工具调用与结构化输出仍需验证。包名中的 OpenAI 指兼容接口适配器，模型服务仍配置为百炼。三个步骤使用各自的配置，不在依赖文件中保存模型 ID 或密钥。

## 4. 安装与核验

新机器先按 [完整安装说明](installation.md) 准备系统工具，再运行 `scripts/setup.ps1`。脚本包含锁文件安装、前端构建和实际媒体验证；下面的命令供开发时按需单独操作。

以下 PowerShell 命令从项目根目录开始执行。安装分别使用项目虚拟环境和前端 `node_modules`，不修改全局 Python 包。

只安装集成端运行依赖：

```powershell
uv sync --project backend --locked --no-dev
```

集成端开发环境（包含 pytest、ruff）：

```powershell
uv sync --project backend --locked
```

第 1 人需要内容模块时，使用独立环境：

```powershell
$env:UV_PROJECT_ENVIRONMENT = '.venv-content'
try {
    uv sync --project backend --locked --extra content
} finally {
    Remove-Item Env:UV_PROJECT_ENVIRONMENT
}
```

前端依赖：

```powershell
npm.cmd --prefix frontend ci
```

媒体工具可用性：

```powershell
ffmpeg -version
ffprobe -version
```

抖音发布方式与权限仍待核验，暂不添加未经确定的抖音 SDK 或浏览器自动化依赖。

## 5. 版本维护与验证边界

直接依赖采用精确版本；安装时使用锁文件。更新后端依赖后运行 `uv lock --project backend`，更新前端依赖后在 `frontend/` 运行 npm 安装命令并提交对应锁文件。不要手工修改锁文件中的间接依赖版本。

本次已完成锁文件安装、内容依赖导入、前端构建、后端测试和真实媒体环境自检。安装包括可选内容组，位于项目 `backend/.venv`；没有修改全局 Python 包。真实模型生成与抖音发布尚未验证，详情见 [本机运行](本机运行.md)。
