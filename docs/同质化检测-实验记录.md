# BGE-M3 与 Qdrant 本地模式实验记录

日期：2026-09-23。状态：首个独立实验完成；正式业务接口尚未实现。

本文件记录早期原型。正式业务实现和后续验证已推进，当前状态见 [交付与验收](同质化检测-交付与验收.md)，不再以本文“尚未实现”描述当前状态。

## 问题与结论

验证用户提供的 BGE-M3 是否能生成真实中文向量，并通过 Qdrant 本地集合完成相似检索、排除自身、重复 upsert 和持久化重开。

结论：本次固定语料实验全部执行完成。它证明基础技术链路可用，不证明生产稿件查重质量、服务端部署、并发性能或跨库恢复。

## 可复现环境

- Python 3.11.15，CPU 推理，2 个 Torch 线程。
- BAAI/bge-m3，1024 维 dense 向量，CLS pooling、L2 归一化、Cosine 距离；双方原文输入，不加检索指令。
- 本地模型版本指纹：`local-sha256:2b0617a475299ad48c2346dcab71d07f7adb4887694de1edb4c0fba6b858bd41`。
- 模型目录名 master 不作为不可变版本。脚本对 10 个参与推理的模型/分词器/配置文件生成 SHA-256 清单，原始报告保留清单。
- qdrant-client 1.19.1，本地磁盘模式，临时目录；未启动 Qdrant 服务端。
- sentence-transformers 5.7.0、transformers 5.17.0、torch 2.14.0、numpy 2.4.6；准确依赖由 backend/uv.lock 锁定。
- 模型上限 8192 token；脚本对输入先做 token 计数，超过直接失败。本次没有静默截断。
- 实验索引版本：`probe-bge-m3-dense-cls-l2-cosine-v1`；top_k=10，阈值=0.85。

从 backend 执行：

```powershell
uv sync --locked --extra similarity-probe
.venv/Scripts/python.exe -X utf8 prototypes/similarity_probe.py --model-path "<本机 BGE-M3 完整目录>"
```

模型不随代码提交；--model-path 指向含 pytorch_model.bin、config.json、modules.json 和 tokenizer.json 的目录。此机器由用户提供已有权重，无新增模型下载、无收费模型 API 调用。

## 固定语料与真实结果

历史稿：绿萝喜欢明亮的散射光，不要放在太阳下暴晒。浇水前摸一摸盆土，表层干了再浇透，避免花盆积水导致烂根。冬天生长慢，要减少浇水。

近似改写：养绿萝要放在光线明亮但没有阳光直射的位置。等盆土表面变干后再一次浇透，盆底不能存水，否则容易烂根。到了冬季，绿萝长得慢，浇水次数也要减少。

不同主题：乘坐高铁出行，请提前核对车次和发车时间，携带有效身份证件。到站后按照指示完成安检，在对应检票口候车，检票结束前及时进站。

| 查询 | Qdrant 原始分数 | passed | 判定 |
| --- | --- | --- | --- |
| 与历史稿同文 | 1.0000000217199976 | false | >= 0.85，拦截 |
| 近似改写 | 0.944960945213866 | false | >= 0.85，拦截 |
| 不同主题 | 0.4021696712156153 | true | < 0.85，通过 |

同文分数因浮点舍入略大于 1，保留原始观测值；正式接口需明确容差及展示处理，不能把它解释为超过 100% 的重复率。本实验没有为达到阈值调整文本或分数。

子进程包含导入依赖、模型文件哈希、权重加载和四条文本推理，共 28.0566 秒。实验超时预算 120 秒；该耗时不等于常驻模型单请求延迟，也不证明总方案 P50/P95 性能目标。

## 行为验证

人工边界是原型中的确定性断言，不是已完成正式模块替身回归测试。库中只有一条历史，所以未验证超过十条历史时的排序边界。

原始 JSON 位于 `data/tmp/similarity-probe-bge-m3.json`，包含 4 条完整 1024 维向量、范数、token 数、文件摘要、包版本、运行时间及查询结果。该目录被 Git 忽略，运行数据不进入仓库。
