# 项目目录

新机器安装入口：[安装与运行](installation.md)。运行 `scripts/setup.ps1`、`scripts/start.ps1` 和 `scripts/verify.ps1` 完成安装、启动与环境验证。

开发对接入口：[四模块 HTTP 接口协议 v1](HTTP接口协议.md)（待评审），领域词汇见 [CONTEXT.md](../CONTEXT.md)。

团队协作入口：[代码开发规范](开发规范.md)，包含模块边界、编码要求、分支与 PR 流程、验证命令和交接模板。

当前包含依赖与锁文件、环境自检 API／Worker、独立内容服务及主管 Skill。配音、数字人和完整视频链路按模块继续接入；空目录通过 `.gitkeep` 纳入 Git，不代表功能已实现。

根目录包含运行配置和以下六个文件夹；Git 初始化后另有隐藏的 `.git/` 元数据目录。

后续实现依据 [技术框架](技术框架.md)，依赖用途见 [依赖与环境](依赖与环境.md)，安装、启停与环境自检见 [安装与运行](installation.md)，内容模块配置与验证范围见 [内容服务](content-service.md)。Skills 目录中的选题和策略占位不代表本版增加对应功能；本版不生成字幕。

内容生成复用 app/content/providers/bailian.py 的 TextGenerator/TextReviewer 和 deepagents_client.py，成员实例通过 app/content/agents.py 统一组装。生成与审核分别加载对应 Skill 以及共同主管 Skill。运行目录使用 backend/skills，不迁移到 .claude/skills；同质化已通过 stdio vector-mcp 兼容接入，其规则文档不代表已完成 SDK Skill 加载验收。其余成员按 [六人接口基线](specs/content-agent-baseline.md) 逐个交付，目标目录不等于已实现。

前后端已设置虚拟环境、缓存、构建产物和本地环境文件的忽略规则。引入其他真实配置及运行数据前，应补充对应忽略规则；凭据、模型权重及业务素材不提交。
