团队协作入口：[代码开发规范](开发规范.md)，包含模块边界、编码要求、分支与 PR 流程、验证命令和交接模板。

成员开工入口：[成员开发任务入口](成员开发任务入口.md)；接口候选基线、已确认目录与启动约定，以及已确认的两批共享安排见 [协作开工对齐](协作开工对齐.md)。

汇报材料：[项目开发与小组任务分配方案](项目开发与小组任务分配汇报.md)（2026-09-22），包含当前进展、四人交付、阶段安排、待确认事项与口头汇报稿。

本批共享代码包含目录骨架、依赖与锁文件、公共契约、API／自检 Worker、环境自检页面及本机启停脚本。陈思锴另有本地生产任务存储与 HTTP 接入实现，留待 B 批交付，本批不包含这些业务代码。真实生成服务、生产 Worker 和 Skill 指令尚未作为可用能力交付；下方目录树用于说明基础结构，新约定的服务目录见文末表格，不表示目录或服务已经实现。
