# 项目目录

新机器安装入口：[安装与运行](installation.md)。运行 `scripts/setup.ps1`、`scripts/start.ps1` 和 `scripts/verify.ps1` 完成安装、启动与环境验证。

当前包含目录骨架、依赖与锁文件、最小 API／Worker、环境自检页面及本机启停脚本。真实生产模块和 Skill 指令仍待实现，空目录通过 `.gitkeep` 纳入 Git。

根目录的项目内容只包含以下六个文件夹；Git 初始化后另有隐藏的 `.git/` 元数据目录。

```text
VideoGenerateDemo/
├── docs/                         # 需求、方案、术语和使用说明
├── backend/
│   ├── pyproject.toml           # 集成依赖、可选内容依赖及开发依赖
│   ├── uv.lock                  # Python 依赖锁文件
│   ├── .python-version          # Python 3.11
│   ├── app/
│   │   ├── main.py             # HTTP API 与前端静态文件
│   │   ├── runtime.py          # SQLite、自检状态与心跳
│   │   ├── worker.py           # 独立自检 Worker
│   │   ├── media.py            # FFmpeg 环境自检
│   │   └── providers/            # 外部接口适配
│   ├── skills/
│   │   ├── topic-discovery/      # 选题规则
│   │   ├── spoken-script/        # 写稿规则
│   │   ├── content-review/       # 检查规则
│   │   └── strategy-explanation/ # 策略解释规则
│   ├── tts/                      # 音频服务预留，第 2 人选型
│   ├── migrations/
│   │   └── versions/             # 数据库迁移版本
│   ├── tests/
│   └── fonts/
├── frontend/
│   ├── package.json             # React、Vite、TypeScript 与 Ant Design
│   ├── package-lock.json        # 前端依赖锁文件
│   ├── index.html              # 页面入口
│   ├── vite.config.ts          # 开发与构建配置
│   ├── tsconfig.json           # TypeScript 配置
│   ├── src/
│   │   ├── main.tsx            # 本机环境自检页面
│   │   ├── style.css           # 页面样式
│   │   ├── pages/                # 主题、人物、任务、预览与发布结果
│   │   └── components/
│   └── tests/
├── scripts/                      # 启停、状态、备份与恢复脚本
├── data/
│   ├── assets/                   # 图片、录音、音频和视频
│   ├── models/                   # 模型权重
│   ├── checkpoints/             # 智能体步骤恢复数据
│   ├── tts-state/               # TTS 作业与音色缓存
│   ├── tmp/
│   ├── logs/
│   └── backups/
└── config/                       # 配置模板与本地配置
```

后续实现依据 [技术框架](技术框架.md)，依赖用途见 [依赖与环境](依赖与环境.md)，启停与已验证范围见 [本机运行](本机运行.md)。Skills 目录中的选题和策略占位不代表本版增加对应功能；本版不生成字幕。

前后端已设置虚拟环境、缓存、构建产物和本地环境文件的忽略规则。引入其他真实配置及运行数据前，应补充对应忽略规则；凭据、模型权重及业务素材不提交。
