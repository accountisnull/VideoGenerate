# 项目目录

当前仅创建目录骨架，保留已有项目文档，不包含应用代码、配置内容或 Skill 指令。空目录通过 `.gitkeep` 纳入 Git。

根目录的项目内容只包含以下六个文件夹；Git 初始化后另有隐藏的 `.git/` 元数据目录。

```text
VideoGenerateDemo/
├── docs/                         # 需求、方案、术语和使用说明
├── backend/
│   ├── app/
│   │   └── providers/            # 外部接口适配
│   ├── skills/
│   │   ├── topic-discovery/      # 选题规则
│   │   ├── spoken-script/        # 写稿规则
│   │   ├── content-review/       # 检查规则
│   │   └── strategy-explanation/ # 策略解释规则
│   ├── tts/                      # 独立 CosyVoice 服务
│   ├── migrations/
│   │   └── versions/             # 数据库迁移版本
│   ├── tests/
│   └── fonts/
├── frontend/
│   ├── src/
│   │   ├── pages/                # 配置、任务、指标与策略页面
│   │   └── components/
│   └── tests/
├── scripts/                      # 启停、状态、备份与恢复脚本
├── data/
│   ├── assets/                   # 图片、录音、音频、字幕和视频
│   ├── models/                   # 模型权重
│   ├── checkpoints/             # 智能体步骤恢复数据
│   ├── tts-state/               # TTS 作业与音色缓存
│   ├── tmp/
│   ├── logs/
│   └── backups/
└── config/                       # 配置模板与本地配置
```

后续实现依据 [技术方案](技术方案.md)、[PRD](视频生成平台PRD.md) 和 [开发实施计划](开发实施计划.md)。文档中列出的 Python、前端、配置和 Skill 文件仍属于未来实现规划。

当前提交仅包含文档和空目录占位文件。引入真实配置、运行数据和构建产物之前，应先在对应子目录设置忽略规则；凭据、模型权重及业务素材不提交。
