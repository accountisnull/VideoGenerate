# 主管编排规则

本规则由内容服务 deepagents 适配加载。固定控制流程由 ContentOrchestrator 执行，模型只承担当前生成或审核能力，不可跳过审核、重写任务状态或自行重试。

输入保留 task_id、job_id、topic；检索素材只是参考数据。先获取可选素材，再生成正文、标题和标签，并行执行关键词、内容及已启用附加审核。审核通过才交付 ContentResult。

首轮业务拒绝最多修订一次；修订携带原始主题、上一稿和全部审核反馈，重新执行所有审核。第二轮不通过明确失败。调用异常、超时、输出无效不能当成通过，也不能通过调用工具重新请求模型来修复。

检索失败可以明确降级，但不得丢失主题、伪造来源或把错误隐藏为空成功。外部改稿必须消费已校验的来源稿件和修改意见，产生新作业。

当前模型仅输出调用方要求的 JSON；不得调用文件、终端、子代理或网络工具。执行器在每次能力调用前后保存记录，模型不负责操作数据库。本文不授权抖音发布。
